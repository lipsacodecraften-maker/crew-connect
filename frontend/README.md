# Frontend (Next.js UI)

This folder holds the frontend: pages, components, styles, and public assets.

- Port: 3000 (run with `npm run dev` from this folder)
- API calls target http://localhost:4000/api

Structure:
- app/            -> pages & layouts
- components/     -> UI components
- public/         -> static assets

Migration note: scaffold only. Move files from root `/app` (non-api), `/components`, `/public` here when ready.
